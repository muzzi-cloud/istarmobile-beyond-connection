# i.starmobile — 3D-inspired storefront

A responsive, single-page mobile and accessories storefront concept built with HTML, CSS and vanilla JavaScript.

## Open
Open `index.html` in a modern browser. No build tools are required.

## Included
- Responsive navigation and product search
- 3D-inspired CSS smartphone hero and product artwork
- Smartphone and accessory listings
- Add-to-cart interactions, quantity controls and cart drawer
- Newsletter form demo
- Mobile menu and reduced-motion support

## Important demo notes
- Prices and product names are sample storefront content and should be verified before launch.
- Checkout is not connected to a payment gateway.
- Newsletter submission is not connected to an email marketing service.
- Account, wishlist, shipping, and order-tracking links are placeholders.
- Google Fonts requires an internet connection; system fonts are used as fallback.
